# Авиааналитика

Запустите Docker Desktop с Linux-контейнерами. В каталоге дистрибутива выполните:

~~~powershell
Copy-Item .env.example .env
docker compose up --build -d
docker compose ps
~~~

Откройте [Авиааналитику на localhost:8080](http://localhost:8080). При первом старте MongoDB загружает готовые коллекции из `avia_archive`. За ходом импорта можно следить командой `docker compose logs -f mongo`. Обычный перезапуск использует существующий том.

В `.env` можно изменить `AVIA_HTTP_PORT` и указать `AVIASALES_TOKEN` и `AERODATABOX_API_KEY` для загрузки свежих данных. Для просмотра подготовленных результатов ключи не требуются. Во вкладке прогноза доступны будущие вылеты из ценовых снимков, для которых есть общий профиль цены и задержки. Когда сохранённые вылеты пройдут, обновите список через вкладку «Обновить данные».

Обе модели входят в папку. При первом запросе прогноза ONNX-модель загружается в память. Если в папке есть `models/original/price_model.onnx`, приложение использует компактное представление тех же деревьев. Если приложение не открывается, проверьте состояние контейнеров командой `docker compose ps` и сообщения `docker compose logs app delay mongo`.

Остановить приложение с сохранением данных можно командой `docker compose down`.
