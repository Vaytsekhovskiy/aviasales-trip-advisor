06Динамика задержек по датам

Медиана по календарной дате scheduled departure local. Пропуски отображаются разрывами, а не нулевой задержкой.

Источник: нормализованные физические рейсы AeroDataBox. N — число неотменённых рейсов с доступной задержкой соответствующего типа. Для P(delay > 15/30/60) используются строгие пороги и только доступные задержки вылета. Отмены исключены из задержек; их доля рассчитана по всем рейсам. В этой версии используются все доступные delay-значения без дополнительного фильтра статусов, как в FlightHistoryAggregator. Revised time может оставаться оценкой API. Наблюдаемые различия не доказывают причинность; состав маршрутов, сезон и полнота данных влияют на сравнения. Повторная дедупликация не выполнялась.
